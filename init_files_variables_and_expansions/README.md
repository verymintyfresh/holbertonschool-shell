## What is this directory?

This is the directory for the Init files, Variables and Expansions project.

| File | Description |
| ---- | ----------- |
| 0-alias | Sets an alias in the shell. |
| 1-hello\_you | Greets the current user. |
| 2-path | Adds a directory to the PATH. |
| 3-paths | Counts the number of directories in the PATH. |
| 4-global\_variables | Prints the user's environment variables. |
| 5-local\_variables | Prints the shell-set variables. |
| 6-create\_local\_variable | Sets a local variable. |
| 7-create\_global\_variable | Sets a global variable. |
| 8-true\_knowledge | Adds a variable to a constant. |
| 9-divide\_and\_rule | Divides one variable by another. |
| 10-love\_exponent\_breath | Raises one variable to the power of another. |
| 11-binary\_to\_decimal | Converts a variable to a different base. |
| 12-combinations | Prints combinations of letters matching a specific pattern. |
| 13-print\_float | Prints a number with a specified number of decimal places. |
| 14-decimal\_to\_hexadecimal | Converts a variable to a different base. |
