## Basics

This folder contains files for the Shell Basics project.
- 0-current\_working\_directory: Prints the absolute path of the current working directory.
- 1-listit: Prints the contents of the current working directory.
- 2-bring\_me\_home: Changes directory to the user's home directory.
- 3-listfiles: Lists the contents of the current working directory in long format.
- 4-listmorefiles: As 3-listfiles, but with hidden files included.
- 5-listfilesdigitonly: As 4-listmorefiles, but with UID/GID only displayed numerically.
- 6-firstdirectory: Creates the directory /tmp/my\_first\_directory.
- 7-movethatfile: Moves a file from /tmp to a subdirectory.
- 8-firstdelete: Deletes a file in a subdirectory of /tmp.
- 9-firstdirdeletion: Deletes a subdirectory of /tmp.
- 10-back: Changes the current working directory to the previous working directory.
- 11-lists: Lists the contents of specific directories in long format, with hidden files included.
- 12-file\_type: Prints information about a specific file.
