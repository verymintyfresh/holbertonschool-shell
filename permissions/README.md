## About this directory

This directory contains files for the Permissions project.

| File | Description |
| ---- | ----------- |
| 0-iam\_betty | Changes the current user. |
| 1-who\_am\_i | Prints the current user. |
| 2-groups | Prints the groups the current user is in. |
| 3-new\_owner | Changes the owner of a file. |
| 4-empty | Creates a new file. |
| 5-execute | Adds executable permissions to a file. |
| 6-multiple\_permissions | Changes multiple permissions on a file at once. |
| 7-everybody | As above. |
| 8-James\_Bond | Sets permissions 007 on a file. | 
| 9-John\_Doe | Sets different permissions on a file. |
| 10-mirror\_permissions | Copies permissions from one file to another. |
| 11-directories\_permissions | Recursively sets execute permissions on directories only. |
| 12-directory\_permissions | Creates a directory with specific permissions. |
| 13-change\_group | Changes just the group of a specific file. | 
| 14-change\_owner\_and\_group | Changes the owner and group of a specific file. |
| 15-symbolic\_link\_permissions | Changes the owner and group of a symbolic link. |
