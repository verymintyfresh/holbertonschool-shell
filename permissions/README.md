## About this directory

This directory contains files for the Permissions project.

| File | Description |
| ---- | ----------- |
| 0-iam\_betty | Changes the current user. |
| 1-who\_am\_i | Prints the current user. |
| 2-groups | Prints the groups the current user is in. |
| 3-new\_owner | Changes the owner of a file. |
| 4-empty | Creates a new file. |
| 5-execute | Adds executable permissions to a file. |
| 6-multiple\_permissions | Changes multiple permissions on a file at once. |
