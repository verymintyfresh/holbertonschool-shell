## What is this directory?

This is the directory for the IO Redirections and Filters project.

| File | Description |
| ---- | ----------- |
| 0-hello\_world | Prints a message to the standard output. |
| 1-confused\_smiley | Prints a more complicated message to the standard output. |
| 2-hellofile | Prints the content of a specified file to standard output. |
| 3-twofiles | Prints the content of multiple files to standard output. |
| 4-lastlines | Prints the last 10 lines of a specified file to standard output. |
| 5-firstlines | Prints the first 10 lines of a specified file to standard output. |
| 6-third\_line | Prints the third line of a specified file to standard output. |
| 7-file | Creates a file with a ridiculous name. |
| 8-cwd\_state | Writes a directory listing into a file. |
| 9-duplicate\_last\_line | Duplicates the last line of a file. |
| 10-no\_more\_js | Deletes files with a certain extension. |
